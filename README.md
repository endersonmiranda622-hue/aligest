# AlimGest — Gestão Inteligente da Alimentação Escolar (v3)

Sistema web profissional para gestão da alimentação escolar em escolas públicas.

## Novas Funcionalidades Integradas
- **Dupla Comprovação Fotográfica:** Exigência de Foto 1 (Nota Fiscal / Documento de Entrega) e Foto 2 (Alimentos Efetivamente Recebidos).
- **Rastreabilidade de Responsáveis:** Diferenciação entre o responsável pelo recebimento físico na entrega e o utilizador que lançou no sistema.
- **Divergências e Estoque Real:** O estoque reflete a quantidade efetivamente conferida e aceita, mantendo a nota original e a divergência salvas em auditoria.
- **Arquitetura Multi-Escola:** Isolamento rigoroso por `escolaId`.
